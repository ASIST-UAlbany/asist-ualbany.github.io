# Event flyers

Every flyer in this folder shows up on the **Events** page of the website, newest first.

## Add an event

1. **Name the file first**, on your computer, like this:

   `2026-11-05 Fall Mixer.pdf`

   The date goes first as year-month-day (`YYYY-MM-DD`), then a space, then the event name.
   The date decides the order on the page and the name becomes the title.
   Avoid the characters `#`, `?` and `%` in the name.

2. Click **Add file** (top right of this page), then **Upload files**.
3. Drag your flyer in, then click **Commit changes**.
4. Wait about 2 minutes. The website updates on its own.

Accepted formats: **PDF, JPG, PNG** (also WEBP and GIF).
iPhone photos saved as **HEIC will not show up**. Export or screenshot them as JPG or PNG first.

## Fix or remove an event

- To remove one, click the file in the list above, open the **...** menu (or the trash icon), choose **Delete file**, then **Commit changes**.
- To fix a typo in the name or date, the easiest way is to delete the file and upload it again with the right name.

Files without a date at the start of the name still appear, but at the bottom of the list.
