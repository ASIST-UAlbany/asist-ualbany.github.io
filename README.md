# ASIS&T UAlbany website

Site for the UAlbany student chapter of ASIS&T: https://asist-ualbany.github.io/

**Add an event:** upload a flyer to [`flyers/`](flyers/) named like `2026-11-05 Fall Mixer.pdf`. See [`flyers/README.md`](flyers/README.md).

**Edit content:** text in `index.html`, contact links in `src/site.js`, styles in `src/style.css`.

Every push to `main` deploys automatically. Locally: `npm install`, then `npm run dev`.
